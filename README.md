# «ПРОЕКТ: Я» — Тетрадь самоконтроля подростка (13–16 лет)

Современный посадочный сайт (Landing Page) для практической тетради-навигатора по развитию полезных привычек, самоорганизации, тайм-менеджменту и постановке целей на 90 дней.

## Стек технологий
- **HTML5**: Семантическая разметка, нативные диалоги `<dialog closedby="any">`, OpenGraph микроразметка.
- **CSS3**: Космическая дизайн-система, CSS Variables, `@starting-style` анимации, Flexbox & Grid, полная адаптивность (Desktop / Tablet / Mobile).
- **Vanilla JavaScript**: Интерактивный просмотрщик всех 10 разворотов, полноэкранный HD-зум, интерактивный экспресс-тест для родителей с подсчетом баллов, динамический таймер, модальная форма заказа с моментальным откликом.
- **WebP оптимизация**: Сжатие сканов страниц без потери качества (сокращение веса более чем на 90%).

## Структура сайта
1. **Главный экран (Hero)** — 3D-мокап тетради, продающий оффер, плашки доверия.
2. **Цифры и факты** — 1 450+ ребят, 92% прекращения споров, 10 минут в день.

5. **Методика и психология** — Кайдзен, когнитивный рефрейминг, сравнение выгод для ребенка и родителей.
6. **Инициатор проекта** — Мария Маркина (Ученица 11 класса, индивидуальный школьный проект и волонтерство).
7. **Экспресс-тест для родителей** — интерактивная диагностика экранного стресса.

## Подключение Telegram-бота для получения заказов

Уведомления о новых заказах отправляются напрямую в Telegram через Bot API (без необходимости держать сервер или бэкенд).

Конфигурация расположена в файле [`js/config.js`](file:///c:/Projects/Lending%20for%20Maria/js/config.js):

```javascript
window.TELEGRAM_CONFIG = {
  botToken: 'YOUR_BOT_TOKEN', // Токен бота от @BotFather
  chatId: 'YOUR_CHAT_ID',     // Chat ID получателя или группы
  debug: true
};
```

### Как настроить за 2 минуты:
1. **Получить токен бота (`botToken`)**:
   - Напишите в Telegram официальному боту `@BotFather`.
   - Отправьте команду `/newbot`, укажите имя и username бота.
   - Скопируйте выданный API токен в поле `botToken`.
2. **Получить свой Chat ID (`chatId`)**:
   - Напишите боту `@userinfobot` или `@getmyid_bot` в Telegram.
   - Скопируйте ваш `Id` (число) в поле `chatId`.
3. **Активировать бота**:
   - Обязательно откройте вашего созданного бота и нажмите **Start** (`/start`), чтобы бот получил право присылать вам сообщения.
   - *(Для групп/каналов: добавьте бота в чат администратором и укажите ID группы, например `-100...`).*

### Что происходит при заказе:
1. Клиент выбирает тариф и вводит свой **Email**.
2. Клиенту сразу открывается окно с подтверждением: **«Ссылка на оплату направлена на вашу электронную почту»** с указанием его email и выбранного тарифа + всплывающее toast-уведомление.
3. В этот же момент в **Telegram-бот заказчика** приходит форматированное сообщение:
   - Выбранный тариф и цена
   - Email клиента (в теге `<code>` для удобного копирования в 1 клик)
   - Имя и контактные данные (если указаны)
   - Точная дата и время заказа (МСК)
